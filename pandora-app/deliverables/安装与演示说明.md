# 潘多拉 App 安装与演示说明

## 安装前置条件

潘多拉 App 需要连接后端服务才能使用，安装前请确认：

1. 电脑已按仓库根 README 完成 MySQL 建库并启动后端（`http://电脑IP:8080`）。
2. 手机与电脑连接同一局域网。
3. 打包前已将 `pandora-app/android/src/com/pandora/demo/MainActivity.java` 中的 `API_BASE` 改为电脑局域网 IP（如 `http://192.168.x.x:8080/api`）。

## 安装

将构建产出的 APK 发送到安卓手机，保存到文件管理器并打开，按系统提示允许安装。需要 Android 8.0 或以上，Android System WebView／Chrome 保持更新。

若手机上装过旧演示版，请先卸载再安装（本地构建与旧包签名不同）。

## 演示账号

密码与账号相同：`admin`（管理员）、`founder`（创始人）、`manager`（部门经理）、`zhou`（团队长）、`lin`／`chen`（员工）。

## 演示流程

1. **登录**：用 `lin` 登录 App，查看工作台中的任务、公告与今日日志入口。
2. **任务执行**：打开「完成客户方案初稿」（林予安与周一鸣共同负责），保存一条文字进展，再标记完成——完成无需审核。稍后可用 `zhou` 登录查看同一任务的状态与进展记录。
3. **变更审核**：在 Web 管理端（`http://电脑IP:8080`）用 `manager` 登录，派发一条新任务并指定两位负责人，提交后任务不直接出现；再用 `founder` 或 `admin` 登录审核通过，App 端刷新即可看到新任务。编辑、删除任务同样走申请—审核流程，驳回需填写原因，不能审核自己的申请。
4. **每日日志**：在 App 日志页保存今日综合日志，再修改一次并展开查看历史版本；历史日期日志只读，无编辑入口。
5. **工作视图**：切换月／周／日视图，查看任务与日志分布，月视图可点击进入当天。
6. **管理端**：Web 管理端可维护账号、查看全部任务／申请／日志、发布公告、查看统计数据。

## 常见问题

- **App 提示无法连接服务器**：确认后端已启动、手机与电脑同网、`API_BASE` 已改为局域网 IP，并检查电脑防火墙放行 8080 端口。
- **登录失败**：演示账号密码与账号相同；如数据库被清空过，重启后端会重新写入种子数据。
- **数据不共享**：检查是否多台设备连接了同一个后端地址；所有数据以 MySQL 中 `pandora` 库为准。
