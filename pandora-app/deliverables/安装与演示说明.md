## 安装前置条件

潘多拉 App 需要连接后端服务才能使用，安装前请确认：

1. 电脑已按仓库根 README 完成 MySQL 建库并启动后端（`http://电脑IP:8080`）。
2. 手机与电脑连接同一局域网。
3. 打包前已将 `pandora-app/android/src/com/pandora/demo/MainActivity.java` 中的 `API_BASE` 改为电脑局域网 IP（如 `http://192.168.x.x:8080/api`）。

## 安装

将构建产出的 APK 发送到安卓手机，保存到文件管理器并打开，按系统提示允许安装。需要 Android 8.0 或以上，Android System WebView／Chrome 保持更新。

本次新版可覆盖安装上一份 `0.3.0-updated` 安装包；若系统提示签名不兼容，再卸载其他来源的旧演示版后安装。

## 演示流程

1. **登录**：用姓名“林予安”、密码 `lin` 登录 App，查看工作台中的任务、公告和个人日志。
2. **任务执行**：打开「完成客户方案初稿」（林予安与周一鸣共同负责），保存文字进展，再标记完成。稍后可用“周一鸣”登录查看同一任务的状态与记录。
3. **变更审核**：App 视图页可新建任务；普通成员只能给自己创建，管理角色可指定管理范围内的多位负责人。创建、编辑、删除需审核；用“许文清”或“系统管理员”登录 App，在视图页任务列表下方的“任务申请与审核”处理他人的申请。
4. **每日日志**：在日志页或“我的”页记录、补写最近三天的日志；修改后可展开查看历史版本，更早日志只读。
5. **工作视图**：日历可直接选择日期、快捷回到今天；任务表格可按状态、优先级、本人负责和关键词筛选。
6. **个人资料**：在“我的”页查看性别、身份证号、手机号，点击头像选择图片更换。
7. **管理端**：Web 管理端（`http://电脑IP:8080`）维护组织账号、公司公告与十大内容；创建成员时记录一次性展示的初始强密码。

## 常见问题

- **App 提示无法连接服务器**：确认后端已启动、手机与电脑同网、`API_BASE` 已改为局域网 IP，并检查电脑防火墙放行 8080 端口。
- **登录失败**：请使用姓名或手机号；演示姓名及密码见上表，旧内部账号名不再用于登录。
- **数据不共享**：检查是否多台设备连接了同一个后端地址；所有数据以 MySQL 中 `pandora` 库为准。
