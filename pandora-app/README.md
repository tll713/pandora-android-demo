# 潘多拉安卓初版演示

版本 0.2.0，按 2026 年 10 月 14 日提供的甲方聊天截图调整。目标是在一部安卓手机上安装演示，跑通任务、变更审核、工作日志和工作视图。Android 外壳加载随包携带的页面，不依赖电脑启动服务或互联网。

## 安装

安装文件：`deliverables/pandora-demo-0.2.0.apk`。将它发送到安卓手机，在文件管理器中打开，按系统提示允许该来源安装。微信不能直接安装时，先保存到文件管理器再打开。

最低 Android 8.0，系统 Android System WebView／Chrome 需保持更新。本包使用演示签名，供课堂或甲方初版体验，不是应用商店正式发布包。

首次打开默认是“林予安 · 员工”，已包含示例任务和日志。底部为首页、任务、日志、视图、我的。到“我的 → 切换演示身份”可切换角色；“我的 → 进入后台流程演示”模拟 Web 后台，方便在一部手机上演示完整闭环。

## 甲方要求和当前实现

| 甲方截图明确要求 | 初版实现 |
| --- | --- |
| Web 负责后台管理和创建账号 | 手机业务页不放任务创建按钮；单独提供后台流程演示入口和管理员演示账号创建。真实 Web 后台与账号服务未接通。 |
| 时间具体到几点几分 | 截止时间选择日期、小时、分钟；创建记录保留完整时间，展示到分钟。 |
| 一个任务可有多个负责人 | 负责人复选，全部负责人能看到并执行同一项任务。 |
| 不要百分比进度，详情中更新进展 | 取消百分比字段和进度条，任务详情保存文字进展与操作者时间。 |
| 日志便捷，不用每个任务单独写 | 每人每天一篇综合工作日志，标题自动生成，关联任务可选。 |
| 任务完成无需审核 | 任一负责人确认后整项任务直接变为已完成。 |
| 创建、编辑、删除任务要审核 | 变更进入申请队列，由另一位管理员或创始人审核，通过后才生效。驳回必填原因。 |
| 只可修改当天日志 | 仅作者当天可修改，不能改他人、改历史日期或补写过去日期。 |
| 近七天日志、保留日志记录 | 默认显示今天及前六天；历史入口只读保留更早记录，同日修改保留旧版本。 |
| 视图按需求报告 | 基于工作区评审稿的月、周、日视图：月视图展示数量并可进入当天，周／日展示任务时间与日志。具体原报告版式尚需核对。 |
| AI 无所谓 | 本版不接入 AI，优先完成业务流程。 |

## 三分钟演示

1. 切换“沈知夏”，进入后台流程演示，创建“完成客户评审稿”，勾选林予安和周一鸣，选择精确到分钟的截止时间，提交审核。此时员工任务列表不会出现新任务。
2. 切换“许文清”或“系统管理员”，进入后台，查看申请内容并审核通过。
3. 切换“林予安”，在任务详情保存文字进展，再确认完成。切换周一鸣后可见同一项任务已经完成，不再走完成审核。
4. 在日志页保存今日综合记录，再修改一次，打开日志展开历史版本。历史日志中没有编辑入口。
5. 用沈知夏申请编辑或删除任务。审核前原任务保持有效；切换审核人通过后，编辑才生效，删除则归档。待审期间的执行进展不会被编辑申请覆盖。
6. 切换月、周、日视图。关闭并重新打开 App，检查已保存记录。

## 尚未确定的业务规则

以下是可演示的初版假设，不能当作甲方已确认的结论：

- 审核由另一位管理员或创始人执行，不能自审。甲方未给出组织审批层级，暂未实现逐级会签。
- 多人负责采用“任一负责人可标记整项完成”。若要所有人分别确认完成，需要调整状态模型。
- “近七天”理解为默认查看范围，旧日志及修改版本长期保留。没有按七天删除旧记录。
- 每人每天一篇综合日志，重复保存更新该篇。截图强调便捷，没有明确每天能否多篇。
- 任务新增文字进展、完成状态属于执行操作；标题、负责人、截止时间、优先级、原始说明变更才进入审核。
- 角色可见范围沿用原型的部门范围，团队长暂未单独建团队层级。公司派发任务按当前角色权限显示。

## 数据和交付边界

本版完全离线，每部手机保存自己的数据，彼此不共享。身份切换和账号创建是演示功能，没有密码鉴权；这些前端检查不能作为正式安全边界。真实上线需补服务端登录、权限校验、共享数据库、Web 管理端和手机同步。

普通关闭、刷新和重新打开 App 保留记录。卸载或清除应用数据会删除本机记录；无云备份或导出功能。日志日期按设备当地日期判断，设备改时间也会影响判断；正式版应以服务器的业务时区为准。

浏览器旧版 `pandora.workspace.v1` 数据不会被本次清除，新版使用独立的 v2 数据，不自动迁移旧版单负责人／完成审核数据。

原 PDR 文档保持原样，其中百分比进度和完成后审核等旧建议已被本次截图要求替代，应在下一次正式需求稿中同步修订。

## 电脑预览和开发

需要 Node.js 20 或以上：

```powershell
npm start
```

访问 `http://127.0.0.1:5173`。浏览器数据与手机数据独立；此地址不用于手机联机。

```powershell
npm run check
npm test
python scripts/build_android.py --java-home "你的JDK目录"
```

安卓构建使用 JDK 和 Google 官方 Android 35 平台／构建工具。首次构建会下载并缓存在用户缓存目录，不需要安装 Gradle。源码在 `android/`，App 页面在 `src/`。演示签名密钥保存在缓存目录；重装更新应保留该密钥，正式版必须使用受保护的发布签名。

浏览器端到端验证脚本为 `tests/ui.smoke.mjs`，需 Playwright 和 Chrome，并可通过 `PANDORA_RUNTIME_MODULES`、`PANDORA_BROWSER`、`PANDORA_URL` 指定环境。验证产物在 `deliverables/verification`。
