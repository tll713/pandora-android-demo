# 潘多拉 App 端

潘多拉智能掌上工作系统的员工端。全员通过 App 使用：查看并执行任务、记录文字进展、维护每日工作日志、查看月／周／日工作视图与公司公告。页面为原生 HTML/CSS/JS，经安卓 WebView 外壳打包为 APK，也可直接在浏览器预览调试。

App 端本身不保存业务数据，所有数据通过后端 API（默认 `http://127.0.0.1:8080/api`）读写，登录后凭 JWT 访问。

## 浏览器预览（日常开发）

需要 Node.js 20 或以上，并先启动后端（见仓库根 README）：

```powershell
cd pandora-app
npm.cmd start
```

访问 `http://127.0.0.1:5173`，用姓名或手机号登录（演示：`林予安`／`lin`，全部账号见根 README）。修改 `src/` 下代码后刷新浏览器即可验证。

## 功能与甲方诉求对照

| 甲方诉求 | 实现 |
| --- | --- |
| 全员通过 App 使用 | 登录后进入单屏工作台，含四块首页信息板、日志、任务视图与个人信息 |
| 一个任务可有多个负责人 | 负责人多选，全部负责人可见并可执行同一任务 |
| 时间具体到几点几分 | 截止时间精确到分钟，创建与展示均保留时分 |
| 不要百分比进度，详情中更新进展 | 任务详情记录文字进展与操作者、时间，无百分比字段 |
| 任务完成无需审核 | 任一负责人确认后任务直接完成，全体负责人可见结果 |
| 创建、编辑、删除任务要审核 | 变更先提交申请，审核通过才生效；审核期间原任务与进展不受影响 |
| 日志便捷，不用每个任务单独写 | 每人每天一篇综合日志，标题自动生成，关联任务可选 |
| 支持忙碌时补写日志 | 作者可补写或编辑最近三天；更早日志只读，修改保留旧版本 |
| 近七天日志、保留记录 | 默认展示最近七天，更早记录由后端长期保留可查 |
| 视图按需求 | 苹果日历式月／周日期区与当天事务、日志联动，选日期即可查看完整标题、具体时间、负责人、状态、说明、最新动态和当天日志；日视图按 24 小时排列事务，日志作为全天事项置于顶部，同时间多项事务依次显示，默认定位首项事务；点击进入详情处理任务或查看日志 |
| 十大内容 | Web 录入的公司事项、派发重点、个人事项按位置同步到首页，点击查看全文；派发项可打开关联任务，个人事项仅本人可见 |
| 任务创建权限 | 全员可提交创建申请；普通成员只能选自己，管理角色可选管理范围内成员，需另一位管理员或创始人审核 |
| 登录与账号 | 手机号或姓名登录；管理员建号自动生成强密码，账号资料由 Web 管理端维护 |
| 个人资料及头像 | 可查看性别、身份证号、手机号；“我的”页选择图片，居中裁切压缩后保存头像 |
| AI 无所谓 | 一期不接入 AI |

## 验证

```powershell
cd pandora-app
npm.cmd test       :: 业务规则测试（tests/domain.test.mjs）
npm.cmd run check  :: 源码语法检查
```

浏览器测试使用模拟 API，需先启动前端预览服务和本机 Playwright/Edge；通过 `PANDORA_URL`、`PANDORA_RUNTIME_MODULES`、`PANDORA_BROWSER_CHANNEL` 可指定运行环境：

```powershell
node tests/ui.smoke.mjs         # 创建、审核、进展、完成、变更与权限入口
node tests/calendar.ui.mjs      # 十大首页内容、月周日事务、重叠时刻、日期选择与移动布局
node tests/android-network.ui.mjs # 后端运行时验证 Android 来源与 CSP 的真实登录，回归旧白名单问题
node tests/personal.ui.mjs      # 日志、个人资料、密码与头像上传
node tests/ui.layout.smoke.mjs  # 单屏首页及视图布局
```

## 安卓打包

```powershell
cd pandora-app
npm.cmd run build:android
```

构建脚本 `scripts/build_android.py` 使用独立缓存的 Android 35 平台与构建工具，首次构建自动下载，无需安装 Android Studio 或 Gradle。安卓外壳源码在 `android/`。

### 连接后端

外壳通过 `android/src/com/pandora/demo/MainActivity.java` 中的 `API_BASE` 注入 API 地址：

- 模拟器：默认 `http://10.0.2.2:8080/api`，指向电脑本机后端。
- 真机：改为电脑局域网 IP（如 `http://192.168.x.x:8080/api`），手机与电脑连同一网络，后端保持运行。

本机自行构建的 APK 与仓库 Releases 中的包签名不同，同一台手机安装前请先卸载旧版本。

## 目录说明

- `src/`：页面、样式与业务逻辑（`app.js` 视图与交互，`domain.js` 业务规则）。
- `android/`：安卓 WebView 外壳源码。
- `scripts/`：安卓构建脚本。
- `tests/`：业务规则测试与浏览器操作检查。
- `deliverables/`：安装演示说明与验证记录。
