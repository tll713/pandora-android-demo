# 潘多拉安卓初版

面向软件测试实训的安卓离线演示项目，版本 0.2.0。支持多人任务、文字进展、任务变更审核、每日工作日志及月／周／日工作视图。

## 安装和演示

从本仓库 [Releases](../../releases) 下载 `pandora-demo-0.2.0.apk`，传到安卓手机后安装。最低 Android 8.0，需要保持 Android System WebView／Chrome 更新。

首次打开默认使用员工“林予安”。通过“我的 → 切换演示身份”切换负责人和审核人，通过“我的 → 进入后台流程演示”展示创建、编辑、删除的审核闭环。

- [安装与演示说明](pandora-app/deliverables/安装与演示说明.md)
- [完整项目说明、业务假设和验证范围](pandora-app/README.md)

## 主要功能

- 一个任务可有多个负责人，时间精确到分钟。
- 任务详情记录文字进展，任务完成无需审核。
- 创建、编辑、删除任务先提交申请，独立审核通过后生效。
- 每日综合日志，仅本人当天可以修改，保留旧版本及历史日志。
- 月、周、日视图，以及演示身份切换和本地账号管理。

## 运行源码

需要 Node.js 20 或以上，无需安装第三方前端依赖：

```powershell
cd pandora-app
npm start
```

浏览器访问 `http://127.0.0.1:5173`。运行 `npm run check` 和 `npm test` 验证源码；安卓构建方法见完整项目说明。

## 项目结构

- `pandora-app/src/`：页面、样式和业务逻辑。
- `pandora-app/android/`：安卓应用外壳。
- `pandora-app/scripts/`：安卓构建脚本。
- `pandora-app/tests/`：业务和浏览器操作检查。
- `pandora-app/deliverables/`：安装说明和验证记录；安装包在 Releases 下载。
- 根目录 PDR 文档：此前需求评审稿，保留供对照；与本版冲突的旧流程以项目说明中的更新为准。

## 当前边界

本版数据仅保存在本机，后台入口为离线演示，没有真实密码登录、共享数据库、多设备同步或 AI 服务。卸载或清除数据会删除本机记录。演示身份和前端权限检查不等同于正式身份鉴权。

15 项业务测试和浏览器操作检查通过，APK 已完成编译及签名检查；尚未进行安卓真机安装与机型兼容性验证。
