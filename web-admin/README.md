# 潘多拉 Web 管理后台

由 Spring Boot 静态托管的原生 HTML / CSS / JavaScript 管理端，无需安装前端依赖或构建。

## 运行

在项目根目录执行：

```powershell
cd server
.\mvnw.cmd spring-boot:run
```

访问 http://127.0.0.1:8080。使用管理员或创始人的手机号或姓名登录。首次空库启动时的演示姓名/密码：`系统管理员 / admin`、`许文清 / founder`。

## 功能与权限

- **组织与账号**：查看成员，按部门、角色、账号状态和关键词筛选。仅管理员可以创建、编辑、停用普通成员账号或重置密码；管理员及创始人账号受保护。
- **公司公告**：发布、编辑、按分类筛选、置顶、取消置顶和删除公告。
- **十大内容**：管理员、创始人可录入、编辑、发布／停用、删除公司重要事项、公司派发任务和指定成员的个人重要事项；支持搜索、板块、成员和状态筛选。位置为 1～10，同板块同成员不可重复，每个板块最多十项。
- 派发内容必须关联已审核生效的任务，App 仅向有权查看该任务的成员展示；任务创建和修改仍需在 App 申请审核。公司事项全员可见，个人事项仅所选成员本人可见。公告与十大事项独立维护。
- 保存后 App 重新加载工作区即可显示最新内容；停用内容不再出现在首页。个人关注的任务仍在 App 任务列表的“个人重点”中查看。
- 管理员与创始人都可以维护公告；账号维护权限由后端接口校验。
- 建号填写姓名、手机号、部门、角色，可补充性别和身份证号；系统自动生成 18 位强密码，仅在创建成功时展示一次。已有账号可先用姓名登录，手机号为空时由管理员补全。
- 页面提供加载失败重试、空结果提示、表单校验、防重复提交、登录过期退出和移动布局。

## 数据库升级

`server/src/main/resources/schema.sql` 在启动时自动执行，兼容旧库，保留已有业务记录。新增字段：

本次另新增 `highlights` 表，保存板块、展示对象、位置、标题、详细内容、关联任务及发布状态；唯一索引保证每个板块的 1～10 位置不会重复。无需清空已有数据库，重启后端自动建表。

| 表 | 字段 | 用途 |
| --- | --- | --- |
| users | enabled | 账号是否启用，旧账号默认为启用 |
| users | auth_version | 账号维护后使旧登录凭证失效 |
| users | phone | 唯一手机号，支持手机号登录 |
| users | gender / id_number | 性别、身份证号，仅本人及授权管理员可查看 |
| users | avatar_data | 本人上传并压缩后的 JPEG 头像 |
| announcements | pinned | 公告置顶，旧公告默认为未置顶 |

字段存在时跳过新增，可重复启动。停用账号、编辑账号或重置密码后，成员需重新登录；重新启用不会恢复原登录凭证。由于认证签名校验内容升级，本次更新前签发的凭证需要重新登录。

## 验证

后端集成测试使用独立 H2 内存数据库，不修改本地 MySQL 的业务记录：

```powershell
cd server
.\mvnw.cmd test
```

浏览器工作流测试使用模拟 API，自动验证组织账号、公告、三类十大内容维护、权限、错误恢复和移动适配，截图输出到已忽略的 `web-admin/tests/artifacts/`：

```powershell
# 在项目根目录执行
node web-admin/tests/admin.ui.mjs
```

测试脚本默认使用本机 Codex runtime 的 Playwright 和 Edge。也可将 `PANDORA_RUNTIME_MODULES` 指向包含 Playwright 的 node_modules 目录，通过 `PANDORA_BROWSER_CHANNEL` 指定浏览器渠道。

当前列表使用管理接口加载数据，在浏览器中筛选和分页；适合当前演示规模，后续数据量增长时可升级为服务端分页。
