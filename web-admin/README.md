# 潘多拉 Web 管理后台

由 Spring Boot 静态托管的原生 HTML / CSS / JavaScript 管理端，无需安装前端依赖或构建。

## 运行

在项目根目录执行：

```powershell
cd server
.\mvnw.cmd spring-boot:run
```

访问 http://127.0.0.1:8080。使用已有管理员或创始人账号登录。首次空库启动时会生成演示账号：`admin / admin`、`founder / founder`。

## 功能与权限

- **工作台**：任务完成率、待审核申请、逾期任务、日志统计，以及近期任务、团队动态和公告；统计卡片可进入对应列表。
- **任务管理**：关键词、状态、负责人、优先级、逾期筛选和分页；详情展示负责人、说明和进展时间线；支持创建、编辑和删除申请。
- **审核中心**：待审核、已通过、已驳回和全部记录；查看变更前后对比、审核人、原因及时间。本人申请不可自审，驳回必须填写原因。
- **组织与账号**：全局查看成员，按部门、角色、账号状态筛选。仅管理员可以创建、编辑、停用和重置普通成员账号；管理员及创始人账号受保护，无法通过此入口修改或授予这两种身份。
- **工作日志**：按人员、日期、关键词筛选，查看全文和历史版本；保留员工端的日志编辑规则。
- **公司公告**：发布、编辑、分类筛选、置顶、取消置顶和删除确认。
- 两种管理角色都可以管理公告、提交任务变更及审核他人申请。业务接口也会校验权限。
- 后台提供加载失败重试、空结果提示、表单校验、防重复提交、登录过期退出和移动布局。

## 数据库升级

`server/src/main/resources/schema.sql` 在启动时自动执行，兼容旧库，保留已有业务记录。新增字段：

| 表 | 字段 | 用途 |
| --- | --- | --- |
| users | enabled | 账号是否启用，旧账号默认为启用 |
| users | auth_version | 账号维护后使旧登录凭证失效 |
| announcements | pinned | 公告置顶，旧公告默认为未置顶 |

字段存在时跳过新增，可重复启动。停用账号、编辑账号或重置密码后，成员需重新登录；重新启用不会恢复原登录凭证。由于认证签名校验内容升级，本次更新前签发的凭证需要重新登录。

## 验证

后端集成测试使用独立 H2 内存数据库，不修改本地 MySQL 的业务记录：

```powershell
cd server
.\mvnw.cmd test
```

浏览器工作流测试使用模拟 API，自动验证任务、审核、账号、日志、公告、错误恢复和移动适配，截图输出到已忽略的 `web-admin/tests/artifacts/`：

```powershell
# 在项目根目录执行
node web-admin/tests/admin.ui.mjs
```

测试脚本默认使用本机 Codex runtime 的 Playwright 和 Edge。也可将 `PANDORA_RUNTIME_MODULES` 指向包含 Playwright 的 node_modules 目录，通过 `PANDORA_BROWSER_CHANNEL` 指定浏览器渠道。

当前列表使用管理接口加载数据，在浏览器中筛选和分页；适合当前演示规模，后续数据量增长时可升级为服务端分页。
